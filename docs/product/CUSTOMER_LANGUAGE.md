Single glossary for user-facing copy in mobile, web marketing/legal, emails, and store materials. Internal code names, bundle IDs, and migration keys may differ — see [LEGACY_IDENTIFIER_EXCEPTIONS.md](./LEGACY_IDENTIFIER_EXCEPTIONS.md).

## Core terms

| Term | Definition | Capitalization |
|------|------------|----------------|
| **Moment** | One saved voice or typed item in the person's own words | Sentence case in prose; **Moment** as a section label when needed |
| **Archive** | The person's private collection of moments on this device | **Archive** as tab/screen title; "your archive" in sentences |
| **Possible pattern** | A tentative recurrence supported by evidence — not settled | Always "possible pattern" in primary UI; never shorten to "pattern" when implying certainty |
| **Evidence** | The exact moments supporting a suggestion | **Evidence** as section label; "the moments behind it" in prose |
| **Change** | An evidence-backed comparison across time | **Change** / "what may have changed" — never "improvement" or "progress" without evidence |
| **Correct** | User says the suggestion missed; opens correction flow | Button label: **Correct** |
| **Fits** | User agrees the suggestion matches their experience | Button label: **Fits** |
| **Partly fits** | Close but incomplete | Button label: **Partly fits** |
| **Not for me** | User rejects the suggestion for themselves | Button label: **Not for me** |
| **Hide** | User suppresses a suggestion locally | Button label: **Hide** |

## Avoid in primary customer UI

Unless the user typed the word in their moment and you are quoting them:

- belief, proof, theory, diagnosis, blind spot, objective
- engine, signal confidence, pattern certainty
- intelligence, discover/discovery (as product capability)
- analyst, historian, synthesis, lifecycle (as persona labels)
- ChatGPT, OpenAI, Whisper (provider branding)

## Approved sentence patterns

**Observations (generated by ArchiveMe):**

- "ArchiveMe **may** show…"
- "This **might** be the same thread…"
- "These moments **may** repeat a similar theme."
- "This does **not** prove improvement or causation."

**User words vs ArchiveMe words:**

- User moments: quoted or block-style, labeled **Your words** / **From your moment**.
- ArchiveMe suggestions: labeled **ArchiveMe suggestion** / **What ArchiveMe noticed** — visually distinct from user text.

**Empty / early archive:**

- 0 moments: "Save one real moment. ArchiveMe compares it later."
- 1 moment: "One moment saved. Add another when this shows up again."
- 2 moments: "These moments may be related. ArchiveMe needs one more before calling it a pattern."
- 3+ moments: "A possible pattern may be forming. Review the evidence before treating it as settled."

## Prohibited overclaims

Never say ArchiveMe:

- proves a personality trait, diagnosis, or cause
- knows what the user feels or needs without citing moments
- is therapy, medical advice, or emergency support
- sends nothing unless the user chose cloud/sync/transcription (always qualify with "unless you choose…")
- is fully encrypted, 100% secure, or anonymous by default

Use **may**, **might**, **could**, or equivalent tentative phrasing for all generated observations until the user confirms via Fits / Partly fits / Correct.

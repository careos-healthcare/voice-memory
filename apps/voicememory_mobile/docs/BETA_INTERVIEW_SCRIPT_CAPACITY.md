# ArchiveMe — Capacity Yes Beta Interview Script

10-question follow-up for TestFlight testers who completed (or attempted) the capacity-yes wedge.

**Stay in pattern-evidence language.** Take notes; do not quote users publicly without consent.

## When to run

- After day 3–7 of the 7-day beta mission, or
- When a tester saves 3 yes moments (whichever comes first)

~15 minutes. Voice or video optional.

## 10 questions

1. **What did you think the app was for in the first 30 seconds?**

2. **Did "Catch the yes before it costs you" make sense?**

3. **Did you save a real yes moment?**

4. **What stopped you if not?**

5. **Did the 3-moment path feel clear?**

6. **Did the yes loop feel accurate?**

7. **Which part felt useful?**

8. **Which part felt confusing?**

9. **Would you use this again next week?**

10. **Would you pay to keep a private archive of this pattern?**

## Optional probes (only if time)

- Did you review your yes loop after 3 moments?
- Did you answer whether the loop fits?
- Which card on Archive Home felt like too much too soon?

## Scoring notes (internal only)

| Signal | Fit / partly fit / not fit |
| --- | --- |
| First-screen clarity | |
| First yes moment saved | yes / no |
| 3 moments saved | yes / no |
| Loop accuracy | |
| Would pay | yes / maybe / no |

## Do not ask

- Clinical or health-system framing
- Productivity or coaching positioning
- Whether the app claims to know them
- Streak or daily-habit pressure

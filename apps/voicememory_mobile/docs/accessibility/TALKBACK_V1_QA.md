# TalkBack V1 real-device script

Run on a supported Android phone in light, dark, largest supported font, and
Remove animations mode.

1. Complete the promise screen through Record and Type; verify logical focus,
   microphone disclosure, keyboard dismissal, and 48-dp targets.
2. Save a voice moment. Verify the saved announcement, transcript-first reading
   order, saved-evidence quote, full date, source type, uncertainty, and
   correction-action labels.
3. Open the exact moment, play/pause/seek encrypted audio, edit the transcript,
   return, export, and cancel deletion.
4. Save a related second moment. Verify semantic Then/Now labels, chronological
   dates, distinct quotes, and both source-opening actions.
5. Traverse Changes, Archive, recovery, Privacy, Subscription, export, deletion,
   and Account without trapped focus, clipping, color-only meaning, or unlabeled
   controls.
6. Interrupt recording, background/resume, recover and encrypt, then delete a
   separate recovery item.

Record device, API level, app build, failures, and date. An unchecked run is not
a pass.

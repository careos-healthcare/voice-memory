# VoiceOver V1 real-device script

Run on a supported iPhone in light, dark, and maximum practical Dynamic Type.

1. Complete the promise screen using Record and Type; verify focus order,
   microphone disclosure, keyboard dismissal, and 44-point targets.
2. Save a voice moment. Verify “Saved” is announced, transcript precedes the
   interpretation, the quote is announced as saved user evidence, its full date
   is clear, and correction controls describe their result.
3. Open the exact moment, play/pause/seek encrypted audio, edit the transcript,
   return, export, and cancel deletion.
4. Save a related second moment. Verify Then and Now are announced with dates,
   sources, quotes, uncertainty, and separate open-source actions.
5. Traverse Changes chronologically, Archive, recovery, Privacy, Subscription,
   and Account. Verify no clipped legal/pricing text or unlabeled icon.
6. Enable Reduce Motion and repeat navigation and post-save presentation.

Record device, OS, app build, failures, and date. An unchecked run is not a
pass.

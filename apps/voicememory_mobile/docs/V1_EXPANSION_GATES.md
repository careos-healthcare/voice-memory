# V1 expansion gates

Expansion is blocked until V1 proof passes.

The best next move is not more product expansion. It is a sharper V1:

> Record one real moment. Return when it happens again. ArchiveMe shows what repeated, changed, faded, or corrected. Pro keeps the longer trail.

## Gate these future ideas

Do not ship these as live V1 consumer surfaces until proof and paid-intent evidence pass:

- Three-day proof challenge
- One-tap return check-ins expansion beyond existing light check-ins
- Private monthly report
- Ask your archive
- Search as memory retrieval
- Export as premium ownership feature if not fully tested
- Cross-device continuity
- Additional wedge landing pages
- Founder Pro beta
- Private report Pro trigger
- Loop packs
- B2B-lite workplace pressure archive
- Affiliate/partner niches
- Annual plan

## Required before expansion

- First useful proof on real archives
- Live billing verified (RevenueCat, sandbox purchase, restore, entitlement persistence)
- Willingness-to-pay signals for keeping the longer trail
- Beta proof thresholds met (see `beta_expansion_proof_copy.dart`)

## What stays live in V1

- Record → return → compare → first thread
- Primary bottom nav: Record, Archive, Account
- Pro = longer trail (not more AI)
- Prove-enough and capacity-yes wedge routes only

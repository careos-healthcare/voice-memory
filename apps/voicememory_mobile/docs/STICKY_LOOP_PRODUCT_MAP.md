# ArchiveMe sticky loop product map

Branch sequence on `main`: #129–#136.

## Core loop

Save a moment → answer one useful question → see progress → compare over time → review weekly → confirm insight → share safe milestone.

Today's One Question lives on **Record** (not Archive Home) so capture stays the primary action.

## Archive Home priority (after consolidation)

1. Archive summary  
2. Sticky loop: First Week Path → Daily Exercise → Clarity → Then vs Now → Calendar → Review Ritual → Milestone cards  
3. Beta feedback, Pro interest, Milestones tracker  
4. Secondary tools (More archive tools): Return changes, Weekly review history, Next evidence, Watchlist, Depth, etc.

Primary area caps at summary + three cards. Everything else collapses under **More archive tools**.

## Record screen (ready state)

- Main capture (voice / type) stays primary.
- Daily exercise then Today's one question when the sticky loop is active.
- Returning-user and next-moment prompt cards hide while daily exercise or one question is showing (entries 1–6) to avoid duplicate guidance.
- Screenshot mode hides live-user-specific cards.

## Privacy / demo safety

- Sample archive IDs (`sample_archive_*`) excluded from real progress engines.
- Share and milestone copy uses fixed strings + counts only.
- Calendar, clarity, ritual, and insight feedback store metadata only.
- Screenshot mode hides live sticky-loop cards on Archive Home.

## Next non-feature priority

# ArchiveMe — Beta Recruitment Pack

Calm, specific, honest scripts for recruiting TestFlight beta testers. No hype, no clinical claims, no fake social proof.

**Core task for every tester:** Save 3 real moments. Return once. Review what repeated. Tell us if it fits.

**Positioning line:** ArchiveMe is a private evidence archive for noticing what keeps repeating, what changed, and what to watch next.

---

## 5 short DM scripts

1. **Capacity wedge:** “I'm testing ArchiveMe for people who say yes before checking capacity. Would you try saving 3 real moments this week and tell me if the archive shows a pattern?”

2. **Prove enough wedge:** “I'm testing ArchiveMe for people who keep doing more to feel enough. Save 3 moments and tell me if anything useful shows up by the third.”

3. **Private archive:** “I'm looking for 5 people to test a private archive app — no sharing raw entries. Save 3 moments, return once, tell me if it fits.”

4. **Founder peer:** “Building ArchiveMe — evidence over time from your own saved moments. Need honest TestFlight feedback: 3 saves, one return, one sentence on whether it helped.”

5. **Follow-up nudge:** “No rush — if you installed ArchiveMe, the test is just 3 real moments + whether the archive showed anything useful. Happy to remove you from the list if timing is off.”

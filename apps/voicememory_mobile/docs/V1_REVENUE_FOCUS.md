# V1 revenue focus

The revenue increase now comes from sharper packaging, live billing, wedge acquisition, and a cleaner first proof journey — not more product surface.

## What is allowed now

- Record one real moment when something repeats.
- Return later when it shows up again.
- See what repeated, changed, faded, or corrected — cautiously, from saved words.
- Free shows the first useful proof. Pro keeps the longer proof trail.
- Wedge acquisition that funnels into the same record → return → proof loop.
- Live billing claims only after RevenueCat key, App Store products, sandbox purchase, restore, and entitlement persistence are verified.
- Local app lock to protect the archive on this device.

## What is deferred

- Private reports as a live headline or primary Pro promise.
- Exports as a live Pro promise.
- Referrals and safe sharing before first useful proof.
- Android expansion before iOS paid proof.
- B2B before consumer paid proof.
- Loop packs before core Pro conversion.
- Premium tiers before one Pro plan converts.
- Generic Ask/Chat positioning.
- Therapy, diagnosis, treatment, or clinical claims.
- Full anti-sharing / server entitlement protection as a solved feature.

## What must be proven before expansion

Required beta proof:

- 20 invites
- 10 installs
- 10 first saved moments
- 5 users with 3 real moments
- 3 day-2 returns
- 2 willingness-to-pay signals for keeping the longer proof trail

Retention metrics stay diagnostic only: day-2 return, day-7 return, moments across 3+ days, review ritual, copied milestone, export usage.

RevenueCat live proof must pass before App Store metadata claims subscriptions are purchasable.

## Why not add more features yet

ArchiveMe wins when cold users understand one loop quickly: save a repeat, come back, see cautious proof, and optionally keep the longer trail with Pro. More dashboards, reports, sharing loops, tiers, and platform expansion dilute that loop before it converts.
